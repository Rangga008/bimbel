# Fase 3b — Latsol

Bagian kedua Fase 3. **Prasyarat: Fase 3a selesai** (bank soal sudah ada).

## Tujuan
Siswa berlatih dari bank soal dengan feedback instan — beda dari ujian resmi yang timing-nya ketat (itu 3c).

## Cakupan
- Module `latsol`: Admin/Tutor pilih set soal dari bank soal (3a) jadi 1 paket latsol.
- Siswa kerjakan latsol kapan saja (tidak terikat jadwal global seperti exam).
- Setelah siswa submit 1 soal atau selesai 1 paket: **langsung** tampil benar/salah, jawaban siswa, solusi (teks/gambar).
- Halaman "Latsol" (Siswa, Tutor, Admin Academic) dengan data nyata.

## Di luar cakupan
Exam resmi dengan timing global & proctoring (3c/3d).

## Definition of Done
- Siswa mengerjakan 1 paket latsol, feedback benar/salah + solusi tampil langsung tanpa delay/approval.
- Tutor bisa membuat paket latsol baru dari bank soal existing dalam <5 langkah UI.

## Prompt siap-pakai (ringkas)
```
Kerjakan Fase 3b sesuai docs/phases/phase-3b-latsol.md.
Fase 3a sudah selesai, pakai bank soal yang ada. JANGAN kerjakan exam timing/proctoring (itu fase terpisah).
Latsol WAJIB feedback instan setelah siswa submit, beda dengan exam.
Kalau ada tambahan teknis di luar ini, tulis "Usulan Tambahan" saja.
Selesai: ringkas hasil + DoD yang terverifikasi.
```
